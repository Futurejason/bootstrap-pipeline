# 全能问题解决引擎 — 使用说明

## 这是什么？

一个让 AI 按照专业流程帮你解决任何问题的工具。你只需要提出问题，AI 会自动按照六阶段流程处理：

```
提问 → 拆解问题 → 分析资料 → 确认不确定因素 → 规划方案 → 执行验证 → 交付结果
```

## 架构说明

```
universal-problem-solver/
├── entry.md              ← 唯一入口文件（包含平台检测 + 引擎核心）
├── guide.md              ← 使用说明（你正在看的这个）
└── adapters/             ← 各平台适配文件（自动加载，你不需要管）
    ├── kiro.md
    ├── cursor.md
    ├── windsurf.md
    ├── claude-code.md
    ├── chatgpt.md
    ├── claude.md
    ├── coze.md
    ├── doubao.md
    ├── tongyi.md
    ├── wenxin.md
    ├── zhipu.md
    ├── feishu.md
    ├── dify.md
    ├── fastgpt.md
    └── notion.md
```

**核心设计**：`entry.md` 是自包含的——它既包含平台检测逻辑，也包含完整的引擎内容。即使平台不支持文件引用，只粘贴 `entry.md` 的内容就能完整运行。

## 怎么用？

### 方式一：在 Kiro 中（最简单）

**什么都不用做，直接提问。** 引擎已通过 steering 文件自动生效。

### 方式二：在其他平台

只需要做一件事：**把 `entry.md` 的内容粘贴到对应平台的系统提示词/角色设定中。**

| 平台 | 粘贴位置 |
|------|----------|
| **Cursor** | Settings → Rules for AI，或保存为项目根目录的 `.cursorrules` |
| **Windsurf** | AI Rules 设置，或保存为项目根目录的 `.windsurfrules` |
| **Claude Code** | 保存为项目根目录的 `CLAUDE.md` |
| **ChatGPT / GPTs** | 创建 GPT → Instructions |
| **Claude** | 创建 Project → Project Instructions |
| **Coze / 扣子** | 创建 Bot →「人设与回复逻辑」 |
| **豆包** | 创建 Bot →「人设与回复逻辑」 |
| **通义千问** | 自定义助手 →「角色设定」 |
| **文心一言** | 创建应用 →「系统提示词」 |
| **智谱清言** | 创建智能体 →「角色设定」 |
| **飞书** | 创建智能伙伴 →「角色设定」 |
| **Dify** | 创建聊天助手 → 提示词 |
| **FastGPT** | 创建应用 → AI 对话节点系统提示词 |
| **Notion AI** | 设置 → AI → Custom Instructions |
| **其他任何工具** | 找到"系统提示词"或"角色设定"，粘贴 `entry.md` 内容 |

## 使用过程中的交互

### AI 会在每个阶段停下来等你确认

```
✅ 问题拆解 完成 | 摘要：拆解为4个子问题
➡️ 即将进入：资源分析
```

你可以：
- 说 **"继续"** — 进入下一阶段
- 说 **"不对，我的意思是..."** — 修正理解
- 说 **"回到上一步"** — 回退修改

### AI 遇到不确定的事情会问你

```
⚠️ 阻塞性因素：你的"预算30万"是指总投入还是仅启动资金？
- 选项A：总投入 → 启动资金约18万
- 选项B：仅启动资金 → 还需额外准备运营资金
```

你只需要回答选哪个。

### 最终结果附带可信度标注

- ✅ 确定 — 基于你提供的信息
- 🔶 高度可能 — 基于多来源推断
- ⚠️ 推测 — 基于假设，建议验证

## 常用指令

| 你说的话 | AI 会做什么 |
|----------|------------|
| "继续" | 进入下一阶段 |
| "回到上一步" | 回退到上一个阶段 |
| "简化处理" | 当前阶段快速通过 |
| "选方案一" | 选择方案 |
| "重新来" | 从头开始 |
| "为什么这样做？" | 解释决策依据 |

---

## 注意事项

1. **如果 AI 没按流程走**：提醒"请按照六阶段流程来"
2. **如果回答太啰嗦**：说"简化处理，直接给结论"
3. **如果需要附件**：在提问时一起发送
4. **如果对结果不满意**：说"回到方案规划阶段，换一个方案"
5. **新对话 = 新问题**：每个新问题建议开一个新对话
