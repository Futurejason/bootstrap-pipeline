# L2 完整示例：商业方案

## 用户提问

> "我想在福州开一家精品咖啡店，给我一份可行性方案"

## AI 执行过程概要

### Skill 1: classify
```yaml
domain: business-consulting
complexity: L2
expert: business-consultant
recommended_flow: L2-standard
estimated_time: 1day
```

### Skill 2: clarify

P1 决策简报：

```
🔵 D1 — 预算和定位需要确认

情境：在福州开精品咖啡店，需要先明确核心约束

通俗解释：开咖啡店不同档次差别很大。你打算投多少钱、想做什么风格的店，
直接决定了选址、装修、菜单、人员成本。先把这两个定了，方案才有意义。

不清楚的地方：
1. 总预算
2. 风格定位
影响范围：选址、装修、菜单、营销策略

选项 A：30 万预算 + 文艺独立店（推荐）
  ✅ 30 万足够支持一家 60-80㎡ 文艺独立店的启动 + 6 个月运营
  ✅ 福州精品咖啡市场尚有空间，差异化容易做
  ❌ 文艺店客单价虽高但流量受限，需精准选址

选项 B：50 万预算 + 加盟连锁（如 M Stand、Manner 加盟点）
  ✅ 加盟省心，品牌带流量
  ✅ 标准化运营降低管理风险
  ❌ 加盟费 + 装修 + 设备约 50 万起，超出预算门槛
  ❌ 利润率被加盟方压榨

选项 C：15 万预算 + 微型外带店
  ✅ 轻资产快速启动
  ✅ 风险小，回本快
  ❌ 店面小、座位少、客单价低，月利润上限有限

推荐：选项 A
理由：精品咖啡店的差异化机会窗口

默认行为：等待你回复
```

用户回复："30 万预算，文艺独立店，目标年轻白领"

### Skill 4: plan

输出 3 个候选方案 + P2 决策简报：

```
🔵 D2 — 请选择方案

| 维度 | 方案 A：街区精品店 | 方案 B：商场店中店 | 方案 C：办公楼写字楼 |
|------|------------------|-------------------|---------------------|
| 选址 | 鼓楼区文艺街区 | 万象城/苏宁广场 | CBD 写字楼大堂 |
| 月租 | 1.5万 | 2.5万 | 1.2万 |
| 装修预算 | 8万 | 6万（统一规范） | 5万 |
| 客单价 | 35-45元 | 30-40元 | 30-35元 |
| 月营收预估 | 8-12万 | 12-15万 | 6-9万 |
| 月净利率 | 25-30% | 18-22% | 22-28% |
| 回本周期 | 14-18月 | 18-24月 | 16-20月 |
| 风险 | 选址依赖客流 | 商场拒不续约风险 | 工作日依赖 |
| 综合评分 | 8.0/10 | 7.5/10 | 7.2/10 |

推荐：方案 A（街区精品店）
理由：精品咖啡的本质是"目的性消费"，街区店更能建立品牌；30 万预算
匹配最佳；24-35 岁年轻白领乐于探店打卡。

请选择：
- "方案 A" → 继续
- "方案 B" → 切换
- "方案 C" → 切换
- "用推荐的" → 默认采用方案 A

默认行为：采用方案 A，标注「默认采用」
```

用户回复："方案 A"

### Skill 5: execute

输出完整方案文档（约 6000 字），包括：
- 业务模式画布
- 详细财务测算（启动资金明细 + 12 月现金流）
- 选址建议（3 个具体街区 + 评估）
- 菜单设计（精品咖啡 + 季节限定）
- 装修方案（参考案例 + 预算分项）
- 营销计划（开业活动 + 日常运营）
- 实施时间表（开店倒推 4 个月）
- 风险评估（按概率 × 影响排序）

每个章节都附证据链。

### Skill 6: review

```yaml
status: PASSED_WITH_NOTES
scores:
  completeness: 9
  accuracy: 8
  consistency: 9
  feasibility: 8
adversarial_findings:
  - 用户视角：没说"如果选不到合适的店面怎么办"
  - 极端场景：客流月度波动 ≥ 30% 的应对
improvements:
  p1:
    - 补充选址 Plan B（如果 3 个推荐街区都拿不到合适店面）
    - 增加现金流压力测试（营收下降 30% 仍能支撑多久）
```

execute 重做 → 补充上述内容 → review 再次 PASSED。

### Skill 7: deliver

输出完整交付包（保存为 `fuzhou-coffee-shop-plan/docs/business-plan.md` 等）。

## 用户介入次数

3 次：P1（澄清预算）+ P2（选方案）+ P4（验收）。

## 总耗时

约 30-60 分钟（取决于方案细化深度）。

## 关键学习点

- L2 必经 plan 阶段
- 方案对比表必须有真实数字
- review 发现局限后回 execute 重做（不是直接 deliver）
